# Domain Docs

This repository uses a single-context layout.

## Before exploring

After following the handoff instructions in AGENTS.md:

- Read root CONTEXT.md when present.
- Read relevant decisions under docs/adr/.

If these files are absent, proceed silently. Create them lazily through
domain-modeling when terminology or decisions are actually resolved.

## Vocabulary and decisions

Use the terminology defined in CONTEXT.md consistently in issues,
proposals, hypotheses, and tests.

When a needed concept is missing, reconsider the term or record the gap
for domain-modeling.

If a proposal conflicts with an ADR, identify the ADR and explain why
the decision should be reconsidered.
